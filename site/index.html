Chrome Extension

Your YouTube queue, finally simple.

QueUp adds an Add to Que or Remove from Que button to YouTube videos and recommendations, powered by a private playlist named Que.

Install QueUp Open YouTube

Queue from anywhere

Every video card can show a one-click queue action, including recommended videos.

Private by default

Storage lives in your own private YouTube playlist titled Que.

Auto cleanup

When a queued video is watched, QueUp removes it from the playlist automatically.

Jump to queue fast

A prominent Open Que Playlist button appears directly on YouTube.

Install Steps

  1. Set your Google OAuth Client ID in extension/manifest.json.
  2. Open Chrome and go to chrome://extensions.
  3. Enable Developer mode and click Load unpacked.
  4. Select the extension/ folder from this repo.
  5. Open YouTube and use Add to Que.

Built for fast watch later workflows. Privacy policy available at privacy.html.
