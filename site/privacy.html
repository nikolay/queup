Privacy Policy

Last updated: April 29, 2026

Overview

QueUp is a Chrome extension that manages a personal YouTube watch queue by creating and maintaining a private playlist named Que in your YouTube account.

Data We Access

QueUp requests YouTube account access through Google OAuth to read and modify your own playlists and playlist items. This is used only to:

  • Find or create a private playlist named Que.
  • Add videos to that playlist.
  • Remove videos from that playlist when you remove them or complete watching.

Local Storage

The extension stores lightweight local cache data in Chrome extension storage (playlist id and queue lookup map) to improve speed. This data stays on your device.

If Chrome's built-in Google consent prompt is unavailable, QueUp may keep a temporary Google OAuth access token in Chrome session storage so the current browser session can finish YouTube API requests. This token is not written to persistent local storage and expires automatically.

Data Sharing

QueUp does not sell personal data and does not transmit your data to any third-party servers controlled by QueUp.
